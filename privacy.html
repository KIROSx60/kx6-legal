Privacy Policy

Last updated: October 30, 2026

1. Introduction

This Privacy Policy explains how KX6-BOT processes information when providing Discord server management and moderation features.

2. Information We Process

Depending on which features a server enables, KX6-BOT may process:

  • Discord server IDs and user IDs.
  • Server configuration and channel IDs.
  • Role IDs and automatic role settings.
  • Moderation actions and event information.
  • Leveling activity and experience points.
  • Ticket ownership and ticket settings.
  • Message content involved in configured moderation or logging features.

3. How Information Is Used

Information is processed to operate the bot, provide requested server features, maintain configurations, manage tickets, track levels, and perform moderation and logging actions.

4. Storage

KX6-BOT uses local application data files to store server configurations and certain feature-related information.

Some information, such as ticket messages and moderation logs, may also exist in Discord channels according to server settings.

5. Data Retention and Deletion

Server-related application data is retained while needed to operate configured features.

Removing the bot from a server does not necessarily delete messages or other content already stored by Discord in that server.

Server administrators may request deletion of locally stored server data through the support contact provided by the operator.

6. Data Sharing

KX6-BOT interacts with Discord to provide its features. Information may be visible to authorized server members or staff through configured Discord channels.

KX6-BOT does not use server data for advertising.

7. Security

Reasonable measures are used to protect application credentials and stored data. No system can guarantee absolute security.

8. Policy Updates

This policy may change when features or data-handling practices change. Updates will be published here.

9. Contact and Data Requests

For privacy questions or data deletion requests, contact the KX6-BOT operator using the official support contact published alongside the bot.
